# YF-S200 — Hall Effect Pulse Flow Sensor

![YF-S200 Flow Sensor](https://raw.githubusercontent.com/exoticatom/singularity/main/assets/YF-S200-1.jpeg)

📄 [YF-S200 Datasheet](https://raw.githubusercontent.com/exoticatom/singularity/main/assets/YF-S200-Water_flow_sensor_datasheet.pdf)

The YF-S200 (Model YF-21) is a low-cost hall effect flow sensor that outputs a pulse signal proportional to flow rate. Unlike the [SM6004](sm6004.md), it connects directly to an [ESP32](esp32.md) GPIO pin (with a wiring consideration for voltage levels).

---

## Specifications

| Parameter | Value |
|---|---|
| Model | YF-21 |
| Supply voltage | 3.5–24V DC |
| Output | Open collector pulse |
| **Pulse characteristic** | **F = 7Q** (Q = flow in L/min) |
| Flow range | 1–30 L/min |
| Error range | ±5% |
| Connection | 3-wire (Red=VCC, Black=GND, Yellow=Signal) |

### Flow-Pulse Reference

| Flow (L/H) | Frequency (Hz) |
|---|---|
| 120 | 16 |
| 240 | 32.5 |
| 360 | 49.3 |
| 480 | 65.5 |
| 600 | 82 |
| 720 | 90.2 |

Formula: **F(Hz) = 7 × Q(L/min)**

So for ESPHome: at 10s update interval → `multiply = 1 / (7 × 10) = 0.01429 L/min per pulse`

## Signal Level Issue

The YF-S200 is powered at 5V but the ESP32-S3 GPIO is 3.3V maximum. The signal line needs attention:

**However** — the YF-S200 output is **open collector**. It only pulls the line LOW and never drives it HIGH to 5V. This means:

- With ESP32 internal pull-up enabled: line sits at 3.3V (safe), sensor pulls to GND on each pulse
- **No external voltage divider needed** for short cable runs

---

## Wiring — Recommended (Option B: Internal Pull-up)

```
5V  ──── YF-S200 VCC (Red)
GND ──── YF-S200 GND (Black)
         YF-S200 Signal (Yellow) ──── ESP32 GPIO (with internal pull-up)
```

The internal pull-up is enabled in ESPHome config — no external resistor needed.

---

## Wiring — Alternative (Option A: Voltage Divider)

For cable runs over 1m or if signal integrity issues occur:

```
YF-S200 Signal
        │
      10kΩ (R_top)
        │
        ├──────────────► ESP32 GPIO (3.3V safe)
        │
      20kΩ (R_bottom)
        │
       GND
```

Output voltage = 5V × 20kΩ / (10kΩ + 20kΩ) = **3.33V** ✅

## ESPHome Configuration (planned)

```yaml
sensor:
  - platform: pulse_counter
    pin:
      number: GPIOX        # assign safe GPIO
      mode:
        input: true
        pullup: true        # internal 3.3V pull-up
    name: "YF-S200-Flow"
    unit_of_measurement: "L/min"
    update_interval: 10s
    filters:
      # F = 7Q → Q = F/7
      # At 10s interval: pulses counted / 7 / 10 * 60 = L/min
      - multiply: 0.01429  # 1/(7×10) × 60s correction
```

> Note: The datasheet states F = 7Q (Q in L/min). The multiply factor depends on the `update_interval`. For 10s: `multiply = 60 / (7 × 10) = 0.857`. Calibrate against a known volume for best accuracy.

## Notes

- Does **not** connect to [ADS1115](expansion_boards.md) — connects directly to [ESP32](esp32.md) GPIO
- Pulse counting is handled in ESPHome firmware (not HA templates)
- 450 pulses/litre is nominal — calibrate against a known volume for accuracy
- Use Option B (internal pull-up) for short runs, Option A (voltage divider) for longer cables
