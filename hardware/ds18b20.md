# DS18B20 — 1-Wire Digital Temperature Sensor

The DS18B20 is a digital temperature sensor that communicates over a single wire (1-Wire protocol). singularity uses two DS18B20 sensors on GPIO 48.

---

## Sensors (this installation)

| Sensor | Location | ROM Address | Entity |
|---|---|---|---|
| DS18B20-Boil | Boil kettle | `0x750000105cbe3528` | `sensor.ds18b20_boil` |
| DS18B20-HLT | Hot Liquor Tank | `0x3100000c31dd5a28` | `sensor.ds18b20_hlt` |

> ROM addresses are unique per physical sensor. The addresses above are specific to this installation. If a sensor is replaced, rediscover the address using the methods below.

---

## Design Decision — Hardcoded ROM Addresses

singularity uses hardcoded ROM addresses rather than auto-discovery. This ensures each sensor maps permanently to its physical location regardless of boot order or bus scanning sequence. Auto-discovery can assign sensors in random order which causes incorrect location labelling.

## Wiring

```
3.3V
 │
 4.7kΩ (pull-up — mandatory)
 │
 ├──────────────────── ESP32 GPIO 48
 │
 DS18B20 DQ pin

DS18B20:
 ├── VDD → 3.3V
 ├── GND → GND
 └── DQ  → GPIO 48 junction
```

| DS18B20 Pin | Wire colour (typical) | Connect to |
|---|---|---|
| GND | Black | GND |
| DQ | Yellow / White | GPIO 48 + 4.7kΩ to 3.3V |
| VDD | Red | 3.3V |

**The 4.7kΩ pull-up resistor between GPIO 48 and 3.3V is mandatory.** Without it the 1-Wire bus will not function reliably.

### Multiple sensors on same bus

All DS18B20 sensors share the same single wire. Connect in parallel:

```
3.3V
 │
4.7kΩ (one pull-up for entire bus)
 │
 ├──────────────────── ESP32 GPIO 48
 │                          │
 ├── DS18B20-Boil (DQ) ─────┤
 │   VDD → 3.3V             │
 │   GND → GND              │
 │                          │
 └── DS18B20-HLT  (DQ) ─────┘
     VDD → 3.3V
     GND → GND
```

**Key rules:**
- Only **one** 4.7kΩ pull-up resistor for the entire bus — not one per sensor
- All sensor DQ pins connect to the same wire
- All VDD pins connect to 3.3V
- All GND pins connect to common ground
- Maximum recommended stub length per sensor: 10cm from the main bus wire

For cable runs over 1m reduce pull-up to 2.2kΩ.

## ROM Address Discovery

When adding a new DS18B20, the ROM address must be discovered before it can be used. This is a manual step.

**Option A — ESPHome logs with DEBUG (recommended)**
1. Set `logger: level: DEBUG` in `esp32_singularity.yaml`
2. Flash and connect the ESP32
3. Open **HA → ESPHome → singularity → Logs**
4. Look for: `Found 1-Wire device: 0x28XXXXXXXXXXXXXX`
5. Copy the address, add it to the config, set logger back to INFO

**Option B — Remove address field temporarily**
Remove `address:` from the sensor config. ESPHome will scan and report all found devices in logs on boot with a warning "Please add the address to your configuration."

**Option C — ESPHome CLI**
```bash
esphome run esp32_singularity.yaml
```
Watch the serial output on first boot — ROM address appears in the first few seconds.

**Option D — Arduino IDE scanner**
Flash a simple 1-Wire scanner sketch via Arduino IDE. Prints all found addresses to the serial monitor at 115200 baud. Useful for identifying multiple sensors before installation.

> Remember to switch logger back to INFO after capturing the address — DEBUG generates a lot of output.

## Notes

- Supports up to 100+ sensors on a single bus (theoretically)
- Each sensor has a factory-programmed unique 64-bit ROM address
- Temperature range: −55°C to +125°C (±0.5°C accuracy)
- Resolution: 9–12 bit (configurable, default 12-bit = 0.0625°C)
- Parasitic power mode supported (VDD floating) but limited to ~30cm cable runs

---

## Calibration — Offset Correction

DS18B20 sensors are factory-calibrated and typically accurate to ±0.5°C across the full range. For brewing precision a single-point offset correction is usually sufficient.

### How to calibrate

**What you need:** a calibrated reference thermometer and a stable temperature bath (ice water at 0°C or boiling water at 100°C work well).

1. Place DS18B20 and reference thermometer in the same stable temperature bath
2. Wait 2–3 minutes for temperature to stabilise
3. Note the DS18B20 reading from the HA dashboard
4. Calculate offset: `Offset = Reference − DS18B20 reading`
   - Example: reference reads 65.0°C, DS18B20 reads 65.8°C → Offset = −0.8°C
5. Enter the Offset value in HA **Settings tab → DS18B20 Offsets**
6. Takes effect within 1 second — no reflash needed

### Notes
- Recalibrate if you replace a sensor — each has unique factory calibration
- For RIMS use, calibrate at your typical mash temperature range (55–75°C) for best accuracy
- The EMA filter (α=0.25) smooths readings — allow ~5 seconds to stabilise after inserting sensor
- Offset is applied on the ESP32 before publishing to HA — HA always sees the corrected value
