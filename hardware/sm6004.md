# SM6004 — IFM Magnetic-Inductive Flow Sensor

> 🔗 [IFM SM6004 Product Page](https://www.ifm.com/de/en/product/SM6004)
> 📄 [Datasheet](https://raw.githubusercontent.com/exoticatom/singularity/main/assets/SM6004-DataSheet.pdf) | [Manual](https://raw.githubusercontent.com/exoticatom/singularity/main/assets/SM6004-manual.pdf)

The SM6004 is an industrial magnetic-inductive flow meter with dual 4-20mA analog outputs. It measures both volumetric flow and medium temperature.

## Wiring — via 4-20mA to 0-3.3V Converter Module

The SM6004 outputs 4-20mA which cannot be connected directly to the [ESP32](esp32.md) or [ADS1115](expansion_boards.md). A [converter module](current_to_voltage.md) is required.

### Converter Module Setup (AliExpress — 0/4-20mA to 0-3.3V)

1. Set jumper to **4-20mA → 0-3.3V** mode (both J1 jumpers OPEN)
2. Connect module terminals:

| Module terminal | Connect to |
|---|---|
| `VIN+` | 24V PSU positive |
| `VIN−` | 24V PSU GND (common ground) |
| `IN+` | SM6004 OUT2 BK wire (flow signal) |
| `IN−` | 24V PSU GND |
| `VOUT` | ADS1115 input channel + 100nF to GND |
| `GND` | ESP32 / ADS1115 GND |

## Calibration — Actual Procedure (this installation)

> 📖 Full calibration procedure → **[hardware/calibration.md](calibration.md#sm6004--4-20ma-converter--zerospan-calibration)**

You do **not** need to reach 25 L/min or use a current source. Two real-world points are sufficient — the 4-20mA curve is linear.

### Step 1 — ZERO (pump off)
- Stop the pump completely (zero flow through SM6004)
- Measure VOUT with multimeter
- Turn **ZERO** pot until VOUT = **0.00V**

### Step 2 — SPAN (maximum achievable flow)
- Run pump at maximum achievable flow
- Read L/min value off the **SM6004 display**
- Measure VOUT with multimeter at the same time
- Calculate expected voltage: `(L/min ÷ 25) × 3.3`
- Turn **SPAN** pot until VOUT matches that calculated value

### Calibration values (this installation)

| Point | SM6004 display | VOUT set to | Calculated as |
|---|---|---|---|
| Zero flow | 0.0 L/min | 0.000 V | ZERO pot adjusted |
| Max achievable | 13.20 L/min | 1.743 V | (13.20 / 25) × 3.3 |

**Slope:** `13.20 / 1.743 = 7.57 L/min per volt`

### Step 3 — Fine-tune offset from dashboard (after ESP32 connection)

Once connected to ADS1115, the ESP32 reading may differ slightly from the SM6004 display due to ADS1115 input impedance. Use the **flow offset** number entity in the Settings tab to correct this without re-wiring:

1. Run pump at steady flow
2. Note SM6004 display value
3. Note `sensor.singularity_flow1` in HA
4. Set `number.singularity_flow1_offset` = SM6004 display − HA reading
   - Example: display shows 8.3 L/min, HA shows 7.9 L/min → offset = **+0.4**

### Common Ground

All grounds must be tied together:
```
24V PSU GND ──── Module VIN− / IN−
                       │
                       └──── ESP32 GND ──── ADS1115 GND
```

## Full Wiring Diagram

```
24V PSU (+) ──── SM6004 BN (pin 1)
24V PSU (−) ──── SM6004 BU (pin 3)

SM6004 BK (pin 4) ──── Converter IN+
24V PSU GND       ──── Converter IN−
Converter VOUT    ──── ADS1115 ADC_Port_2 (A2 on #1) + 100nF to GND
Converter GND     ──── ESP32 GND
```
