# SM6004 — IFM Magnetic-Inductive Flow Sensor

> 🔗 [IFM SM6004 Product Page](https://www.ifm.com/de/en/product/SM6004)
> 📄 [Datasheet](https://raw.githubusercontent.com/exoticatom/singularity/main/assets/SM6004-DataSheet.pdf) | [Manual](https://raw.githubusercontent.com/exoticatom/singularity/main/assets/SM6004-manual.pdf)

The SM6004 is an industrial magnetic-inductive flow meter with dual 4-20mA analog outputs. It measures both volumetric flow and medium temperature.

## Technical Specifications

| Parameter | Value |
|---|---|
| **Supply voltage** | 20–30V DC (SELV/PELV) |
| **Current consumption** | max 120mA (at 24V) |
| **Outputs** | 2 × analog 4-20mA (scalable) |
| **Number of outputs** | 2 |
| **Flow range** | 0.1–25 L/min |
| **Medium temperature range** | −20 to +80°C |
| **Accuracy** | ±0.5% of full scale |
| **Repeatability** | ±0.15% |
| **Process connection** | G½ male thread |
| **Protection class** | IP67 |
| **Electrical connection** | M12 4-pin connector |
| **Power-on delay** | 5 seconds |
| **Reverse polarity protection** | Yes |

## Output Signals

| Output | Signal | Default scaling |
|---|---|---|
| OUT1 (White) | Temperature | 4mA = 0°C, 20mA = 100°C |
| OUT2 (Black) | Volumetric flow | 4mA = 0 L/min, 20mA = 25 L/min |

## M12 Connector Pinout

| Pin | Wire colour | Function |
|---|---|---|
| 1 | BN (Brown) | Supply+ 24V DC |
| 2 | WH (White) | OUT1 — Temperature 4-20mA |
| 3 | BU (Blue) | GND (supply−) |
| 4 | BK (Black) | OUT2 — Flow 4-20mA |

## Wiring — via 4-20mA to 0-3.3V Converter Module

The SM6004 outputs 4-20mA which cannot be connected directly to the ESP32 or ADS1115. A converter module is required.

### Converter Module Setup (AliExpress — 0/4-20mA to 0-3.3V)

1. Set jumper to **4-20mA → 0-3.3V** mode (both J1 jumpers OPEN)
2. Connect module terminals:

| Module terminal | Connect to |
|---|---|
| `VIN+` | 24V PSU positive |
| `VIN−` | 24V PSU GND (common ground) |
| `IN+` | SM6004 OUT2 BK wire (flow signal) |
| `IN−` | 24V PSU GND |
| `VOUT` | ADS1115 input channel + 100nF to GND |
| `GND` | ESP32 / ADS1115 GND |

### Calibration (one time)

1. Power up — D2 LED should light (confirms power)
2. At minimum flow (4mA): turn **ZERO** pot until VOUT = 0.0V
3. At maximum flow (20mA): turn **SPAN** pot until VOUT = 3.3V

### Common Ground

All grounds must be tied together:
```
24V PSU GND ──── Module VIN− / IN−
                       │
                       └──── ESP32 GND ──── ADS1115 GND
```

## Full Wiring Diagram

```
24V PSU (+) ──── SM6004 BN (pin 1)
24V PSU (−) ──── SM6004 BU (pin 3)

SM6004 BK (pin 4) ──── Converter IN+
24V PSU GND       ──── Converter IN−
Converter VOUT    ──── ADS1115 ADC_Port_4 (A0 on #2) + 100nF to GND
Converter GND     ──── ESP32 GND
```
